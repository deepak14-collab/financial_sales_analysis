Financial Analytics Dashboard
Project Description
The Financial Analytics Dashboard is an interactive business intelligence dashboard designed to analyze and monitor key financial and banking metrics in a simple and visually appealing way.
It provides insights into customers, transactions, accounts, loans, balances, KYC verification status, and branch-wise financial performance.
The dashboard helps banking institutions and financial organizations make data-driven decisions by presenting important KPIs and distributions through charts, graphs, and filters.

Features
1. KPI Cards
Displays overall financial statistics:


Total Customers: 1K


Total Transactions: 2K


Total Accounts: 1K


Total Loans: ₹130M


Total Balance: ₹25.6M


These KPIs provide a quick overview of organizational performance.

2. Customer Analysis
The Top Customers bar chart identifies customers with the highest account balances.
Purpose:


Helps banks identify premium customers


Useful for customer relationship management


Supports personalized banking services



3. Account Type Distribution
The donut chart categorizes accounts into:


Savings Accounts


Current Accounts


Purpose:


Understand customer account preferences


Analyze banking product adoption



4. Loan Status Distribution
Displays:


Active Loans


Closed Loans


Purpose:


Track loan portfolio health


Monitor repayment trends


Evaluate lending performance



5. Transaction Type Distribution
Shows:


Deposits


Withdrawals


Purpose:


Understand customer transaction behavior


Analyze cash flow activities



6. KYC Status Analysis
Classifies customers into:


Completed


Pending


Under Review


Purpose:


Monitor regulatory compliance


Ensure customer verification processes



7. Branch-wise Balance Analysis
Compares balances across multiple branches.
Purpose:


Measure branch performance


Identify high-performing branches


Assist in strategic financial planning
